_Hyde_ is a brazen two-column theme for [Cecil](https://cecil.app) that pairs a prominent sidebar with uncomplicated content. It's based on [Poole](https://github.com/poole/poole), the Jekyll butler, and on the original [Hyde theme](https://github.com/poole/hyde) by [@mdo](https://github.com/mdo).

## Features

- Sidebar with site title, description and main menu
- Optional sticky sidebar content
- Eight color schemes, plus a Cecil one
- Reverse layout, to move the sidebar to the right
- Blog section, tags and pagination
- French translation

## Installation

```bash
composer require cecil/theme-hyde
```

Then add `hyde` to the `theme` section of your `config.yml`.
