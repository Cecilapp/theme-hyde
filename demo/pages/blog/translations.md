The theme supports localization and provides a French translation. Switch to the French version of this site to see it in action.

<!-- excerpt -->

Declare the language in your `config.yml`:

```yaml
languages:
  - code: fr
    locale: fr_FR
```

Then create the translated pages with the `.fr.md` suffix, for example `about.fr.md`.
